# Tensor Quest

An interactive, gamified guide to how AI works — 97 hands-on labs covering tokens, embeddings, attention, LoRA, VeRA, quantization, backpropagation, RAG, and much more. Each lab has quests, hints, a quiz question and a badge, and you level up as you earn XP.

It's a single self-contained HTML file (vanilla HTML/CSS/JS, no build step, no dependencies). Progress is saved in your browser's localStorage.

## Run it

Open `index.html` in any modern browser — or serve the folder:

```bash
python3 -m http.server 8000
```

then visit http://localhost:8000.
